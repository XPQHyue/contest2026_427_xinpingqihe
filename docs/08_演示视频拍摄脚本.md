## 一、录制方案

### A. 真机画面（主素材）

真机没有视频输出，**用手机/相机拍 AMOLED 屏**：

1. 板子固定（手机支架 + 板子立起），避免反光；屏幕亮度调到 80–100。
2. **一段一个 boot**：同一 boot 内运行第二个 `phywear` GUI 会挂在 LCD 驱动里（实测），录坏就 RTS 复位重来。
3. 触控演示建议用指尖侧面轻点，避免遮挡画面。
4. 串口控制台**单独录屏**（叠加"真机实测"文字证据）：
   `picocom -b 1000000 --noreset --lower-rts --lower-dtr /dev/ttyUSB0`

### B. 真机静态证据（插入帧）

- 26 张真机截图 + 2 张总览：`docs/evidence/realboard-20260912/`
- 声学三页：`docs/evidence/acoustic-20260913/{tone,mic,spk}.png`

### C. 性能实测（真机，现场录屏）

```text
lvgldemo benchmark          # 约 90 s，直接录控制台输出
```

> 口径：**用现场实际输出**（当前固件约 41 FPS，render 22 / flush 0；9/12 旧固件为 43 FPS）。
> 不要念稿里的固定数字，念屏幕上出现的数字。

### D. AI 段落（**真机**可演示的部分 + 模拟器补充）

真机（离线能力，**无网络也能演示**）：

```text
复位 → ai_agent &
   期望日志：[agent] Agent loop started, free heap: …
             40 个工具注册（含 phywear_* 4 个）
phywear &                    # 起 GUI，日志出现 installed skill /data/agent/skills/…
ls /data/agent/skills        # 展示 phywear-physics-coach.md（自定义 Skill 落盘）
sleep 600                    # 把 NSH 挂起，让随后输入落到 agent 的 vela> CLI
ask 打开单摆                 # 命中端侧离线意图 → 手表界面真的切到单摆页
```

模拟器（**仅 LLM 对话**需要它——真机没有网络栈；以下命令 2026-09-13 已实测通过）：

```bash
cd ~/openvela
python3 tools/phywear/sim_console.py cmake_out/vela_goldfish-arm64-v8a-ap-phywear \
        --log /tmp/sim.log --in /tmp/sim.in &          # pty + FIFO 控制台
printf 'ai_agent &\n' > /tmp/sim.in                    # 起 Agent（vela> CLI）
printf 'sleep 600\n'  > /tmp/sim.in                    # 挂起 NSH，让后续输入落到 vela>
printf 'set_llm token-plan-cn.xiaomimimo.com mimo-v2.5-pro <KEY>\n' > /tmp/sim.in
printf 'ask 我想用单摆测重力加速度，请直接帮我把实验页打开并开始测量\n' > /tmp/sim.in
# 期望：日志 trace … llm=ok backend=0，且 LLM 自主调用 4 个 phywear 工具后中文作答
```

- ⚠️ MiMo 的 `tp-` 开头密钥是 **Token Plan**，必须配 `token-plan-cn.xiaomimimo.com`；
  用 `set_llm mimo <key>`（指向按量付费端点 `api.xiaomimimo.com`）会直接 401。
- 拍这段时**不要把 Key 露在画面里**：先用 `set_llm` 配好，再 `config_show` 展示（密钥显示为 `tp-c****`）。

> ⚠️ 画面必须打角标：**"LLM 对话：goldfish 模拟器（真机无网络栈）"**。

## 二、分段脚本（总长 4:40，含讲稿要点与字幕）

### 片头（0:00 – 0:08）
- 画面：真机 AMOLED 亮屏特写 + 作品名。
- 字幕：`PhyWear · 腕上智慧物理工坊 · 立创黄山派 SF32LB52 · 2026 openvela AI 硬件大赛`

### 第 1 段 · 一句话定位（0:08 – 0:28，20s）
- 讲：把手机 phyphox 的物理实验搬到手表；玩法灵感来自 phyphox（GPL v3，已声明），我们用 **C + LVGL 独立重实现**。
- 字幕：`玩法来源：phyphox（致谢/GPL）· 实现：C + LVGL（Apache-2.0）`

### 第 2 段 · 真机开机 + 全中文界面（0:28 – 1:05，37s）
- 串口：`phywear lang zh`，画面拍 `SFBL → ABCD → … → NuttShell` 与开机日志；随后拍主菜单宫格滑动。
- 重点拍**原始传感器 6 页**（加速度/陀螺/磁力/环境光/**麦克风**/**扬声器**）。
- 字幕：`真机实拍 · 全中文 · 6 页原始传感器`

### 第 3 段 · 力学实验：单摆测 g（1:05 – 1:45，40s）
- 画面：进入「单摆测 g」，摆动一次，展示实时曲线与结果。
- 讲：`g = 4π²L/T²`，实测偏差约 **1.8%**。
- 字幕：`真机实测：摆测 g 偏差 ≈1.8%`

### 第 4 段 · 声学：发正弦 + 麦克风读数（1:45 – 2:25，40s）
- 画面：声学 → **音频发生器**（频率 −/+ 与预设、音量 −/+、播放/停止）→ 切到原始传感器**麦克风页**看 dBFS 与 32 段电平柱。
- 讲（**必须如实**）：喇叭能出声、麦克风能拾音，但**板载小喇叭声压有限**，常规音量下同板耦合与环境噪声同量级；低频（如 90 Hz）谱峰常落在二次谐波上。
- 字幕：`真机实拍 · 声学通路（响度受板载小喇叭限制，如实说明）`

### 第 5 段 · AI Agent（真机离线 + 模拟器 LLM）（2:25 – 3:05，40s）
- 真机：`ai_agent &` → 日志 `Agent loop started` + 40 工具；`ls /data/agent/skills` 展示自定义 Skill；`ask 打开单摆` 触发表切页（**离线意图**）。
- 模拟器（角标，**已实测，09-13**）：`set_llm token-plan-cn.xiaomimimo.com mimo-v2.5-pro <key>` →
  `ask 我想用单摆测重力加速度，请直接帮我把实验页打开并开始测量`，
  画面打字机式展示日志：`trace … llm=ok backend=0`，LLM **自主发起 4 次工具调用**
  （`phywear_list_experiments` → `phywear_open_screen{pendulum}` → `launch_quickapp` →
  `phywear_run_experiment{pendulum,5s}`），随后中文作答。
- 顺带一句亮点（5 s）：中文技能摘要曾因"按字节截断"变成非法 UTF-8 导致云端 400，
  我们用 `utf8_safe_len()` 修掉（`docs/03 §6.8`）——**这是只有真做端云联调才会遇到的问题**。
- 字幕：`真机：工具/Skill/离线意图 ✅ ｜ LLM 对话：模拟器实测（真机无网络栈，如实）`

### 第 6 段 · 性能与稳定性证据（3:05 – 3:35，30s）
- 画面：`lvgldemo benchmark` 控制台输出（实际数字）→ 叠加真机截图总览。
- 讲：EPIC 硬件加速来自**官方 PR #31/#41/#121**（非本队自研），本队做集成与 UI/算法层优化；启动 **5/5** 复位正常；泡机心跳连续（含声学场景 7 分钟 0 复位）。
- 字幕：`EPIC=官方成果，本队集成 · 启动 5/5 · 泡机 0 复位`

### 第 7 段 · 工程深度：问题定位与工具链（3:35 – 4:15，40s）
- 画面：串口截图工具跑一页（`python3 tools/phywear/pwshot.py shot tone`）+ 三张已采真机截图。
- 讲 4 个真机问题与修复：**组页点击卡死（悬空指针）**、**启动偶发卡死（时钟/晶振建立时序）**、
  **麦克风+喇叭同时工作卡死（AUDCODEC 互斥）**、**切频率爆音（音量爬坡）**。
- 字幕：`4 个真机问题：现象 → 定位 → 修复 → 复现验证`

### 第 8 段 · 结语 + 已知限制 + 归属（4:15 – 4:40，25s）
- 讲（必须出现）：已知限制清单至少 3 条；EPIC 归属官方；灵感来源 phyphox；AI 对话在模拟器。
- 字幕：`已知限制见 docs/01 §已知限制`

## 四、必须出现 / 必须避免（诚实红线）

**必须出现**

- 「EPIC 硬件加速 = 官方 PR #31/#41/#121，非本队自研」（第 1、6、8 段至少各一次）。
- AI 段落角标：**LLM 对话为模拟器环境；真机无网络栈**。
- 声学段落的如实说明：**响度受板载小喇叭限制、同板声耦合弱**。
- 第 2/3 段画面数值性质：**实时传感器读数，非受控实验**（第 3 段除外，摆测 g 是真实测量）。
- 片尾至少 3 条未实现/限制（如：真机无网络栈、主动场景默认关闭、多普勒/声呐未实现）。

**必须避免**

- ❌ 把 EPIC 说成"本队自研/本队适配"。
- ❌ 把模拟器的 LLM 对话说成真机跑通。
- ❌ 把板子静置时的读数说成"实验结果"。
- ❌ 暗示端侧运动识别/主动交互已启用（**默认关闭**，见 [`05_AI_Agent与Skill.md`](05_AI_Agent与Skill.md) §5）。
- ❌ 念稿里没有实测来源的数字（FPS 以现场输出为准）。
- ❌ 画面出现 LLM API Key。
