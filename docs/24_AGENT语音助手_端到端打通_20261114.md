# AGENT 语音助手端到端打通记录（2026-11-14）

## 一句话
板子经蓝牙 PAN 连到 VM 的自研用户态 NAP，说一句话（音频经 VM 侧 vosk 识别），
设备拿到云端 LLM 的真实回答并显示在屏上（AI 页日志环）。

## 架构
```
手表(PANU) --BT PAN/BNEP--> VM 自研 NAP(nap0 192.168.50.1)
      |                          |
      |  TCP 28790 行协议        +-- dnsmasq(DHCP)
      v
VM voiceasr.py  --HTTP 28791--> 浏览器/手机录音页（MediaRecorder）
      |
      +-- ffmpeg 16k mono -> vosk 中文小模型 (ASR)
      +-- HTTPS -> maas.qianwenaiapi.com (deepseek-v4.1-flash-1017)
      +-- 把识别结果与回答推回手表（`X`/`A` 行）
```

## 为什么设备不自带 TLS 直连云端
设备直连时 TLS 握手成功、请求头 325 B 发完，但 16,496 B 的请求体在 400 B MTU 的
BNEP 链路上卡死（tcpdump：发出约 10 KB 后无进展，`mbedtls_ssl_write` 首次调用即阻塞）。
=> 设备做瘦客户端（`pw_relay.c`，约 200 行），HTTPS/LLM 全在 VM。

## 协议（TCP 28790，行协议）
| 方向 | 行 | 含义 |
|---|---|---|
| 设备→VM | `Q <text>` | 同步问答，等一行回答 |
| 设备→VM | `S` | 订阅：VM 有语音输入时主动下发 |
| VM→设备 | `A <text>` | 回答（`pw_ai_note()` 上屏） |
| VM→设备 | `X <text>` | 识别到的原话 |

## 复现
1. VM：`sudo python3 tools/voice/voiceasr.py`（需 `pip install vosk edge-tts` + `ffmpeg`，
   模型放 `/opt/vosk/vosk-model-small-cn-0.22`）
2. VM：`sudo python3 /root/vm_napd3.py` + `dnsmasq --conf-file=/etc/dnsmasq.d/nap0.conf`
3. 板子：复位 → 蓝牙配对（扫描进行中 pair）→ 自动起 PANU → `[relay] subscribed`
4. 浏览器打开 `http://<VM_IP>:28791/`，按住说话；或用
   `curl -F "f=@audio.mp3" http://127.0.0.1:28791/asr`

## 已知边界
- 设备侧无麦克风驱动（树里无 audcodec/I2S 源），语音采集在 PC/手机侧完成。
- 镜像体积极敏感：`nuttx.bin` 2,422,528 B 可启动；加一行 `send()`（2,422,552 B）即
  只打 `SFBL`+`AB`，故设备不做"已上屏"回执，证据取板子自己的 `[relay] push:` 行。
