# PHYWear AGENT 语音助手 · 使用说明（2026-11-14）

## 它现在能做什么

**对着电脑/手机说一句话，手表屏幕上会显示云端大模型的回答。**

链路（全部在 VM 内闭环，不依赖手机热点、不依赖厂商闭源 profile）：

```
手表(PANU) --蓝牙 PAN/BNEP--> VM 自研用户态 NAP (nap0 = 192.168.50.1)
      |                              |
      | TCP 192.168.50.1:28790 行协议 |
      v                              v
  pw_relay.c  <---- A/X 行 ----  voiceasr.py
                                   ├─ 28791 录音页（浏览器按住说话）
                                   ├─ ffmpeg → vosk 中文识别
                                   └─ HTTPS → maas.qianwenaiapi.com（deepseek-v4.1-flash-1017）
```

## 真机证据（板子串口）

```
[netmgr] Found iface tun0 addr 192.168.50.13
[relay] subscribed
[phywear] ai-coach: 我在，说话吧
[relay] push: 我在，说话吧
[relay] heard: 你好请告诉我现在几点了
[phywear] ai-coach: 我这边读不到当前时间，你抬腕看下表盘就行啦，需要我帮别的忙吗？
[relay] push: 我这边读不到当前时间，你抬腕看下表盘就行啦，需要我帮别的忙吗？
```

## 你要怎么用

1. **确认 VM 侧服务在跑**（两个端口）：
   ```bash
   ssh ubuntu
   sudo python3 /root/vm_napd3.py &                       # NAP（蓝牙网络接入）
   sudo dnsmasq --conf-file=/etc/dnsmasq.d/nap0.conf &    # DHCP/DNS
   sudo python3 /root/voiceasr.py &                       # 语音入口 28790 + 28791
   ```
2. **让手表连上**：复位手表 → VM 里 `bluetoothctl` 扫描（`scan on`）→ 看到 `Name: PhyWear`
   → `pair CD:AB:78:56:34:12`。手表会自动起 PANU、拿 `192.168.50.13`、连上中继
   （串口出现 `[relay] subscribed`）。
3. **说话**：Windows 浏览器打开 <http://192.168.106.100:28791/>，按住蓝色圆钮说话，
   松手后页面显示"你说：…"和回答；**同时回答会推到手表屏上**（AI 页）。

   不想开浏览器也可以直接喂音频：
   ```bash
   curl -F "f=@某段话.mp3" http://127.0.0.1:28791/asr
   ```

## 已知边界（如实）

- **采集不在手表上**：这块板子的固件里还没有麦克风驱动（树里没有 audcodec/I2S 源），
  所以目前是"电脑/手机当耳朵、手表当嘴和脸"。板载录音是可继续做的方向。
- **识别用离线小模型**（vosk `vosk-model-small-cn-0.22`，66 MB）：自然语音（如 edge-tts
  合成音）识别良好；机械感很强的合成音会掉字。
- **镜像体积敏感**：`nuttx.bin` 2,422,528 B 能启动；多 24 字节（2,422,552 B）就只打
  `SFBL`+`AB`。所以设备不做"已上屏"回执，判断依据是板子自己的 `[relay] push:` 行。
- **DHCP 偶发失败**：会退到静态地址 `192.168.50.13`，链路照常可用。

| 文件 | 作用 |
|---|---|
