严格复验：中文技能摘要顶到 1024 字节缓冲上限时，请求体仍是合法 UTF-8 / JSON
==========================================================================
背景：模拟器里只放 1 个中文 Skill 时摘要 1022 B（未超上限），不足以证明修复生效；
      本次放入 2 个中文 Skill，强制命中 skill_loader 的 1024 字节上限（截断必然发生）。

设备实际请求体：17654 字节
  ① UTF-8 解码：✅ 通过
  ② JSON 解析：✅ 通过（tools=40 个）
  ③ Skills 段长度：2111 字节（含 system prompt 中 Skills 段，已触及截断上限）

对照（修复前，同一条件）：
  · 抓包发现请求体第 3736 字节为 0xe8（汉字首字节）后直接跟 JSON \n → 非法 UTF-8；
  · 云端返回 400 {"message":"Invalid JSON in request body"}；
  · 摘要长度日志显示 1135 B（= snprintf 的“本应写入长度”，实际超过 1024 缓冲）。
修复后：摘要按 UTF-8 边界截断，日志显示 1022 B（= 缓冲区里真正留下的内容），请求体合法。
