## 1. 改了什么

- **布局**（`phywear_raw.c` / `raw_build_axis_page()`）：原来 3 行「轴字母 + 48 px 大数字」，
  现在改成**一行三列数值**（轴字母 20 px 用 X/Y/Z 系列色，数值 28 px）+ 下方
  **358×186 的迷你实时曲线**，竖直切成 X/Y/Z 三条泳道（每条 62 px），与上方的数值列左右对齐。
  数值不再带单位（列宽 126 px 放不下 `+1234.5 dps`），单位统一标在页面右上角。
- **曲线复用 `pw_scope`**：CPU 光栅化 RGB565 → `lv_image` → EPIC 硬件 blit，与既有曲线页同一路径。
  新增 `pw_scope_set_lanes_i16()`：多泳道 + int16 样本 + 单块缓冲，**不新增 lv_malloc 缓冲**。
  三轴页每页只占 **1 个 scope 槽位**（3 页共 3 槽，`PW_SCOPE_MAX=6`）。
- **自动量程**：纵轴满量程按 1-2-5 步进取档，标注在左下角（如 `+/-2 g`）；右下角标时间窗 `8 s`。
  三页固定量程范围：加速度 1..8 g、陀螺 20..2000 dps、地磁 100..30000 mG。
- **历史样本**：`int16_t g_raw_hist[3][80]`（80 × 100 ms = 8.0 s），**三轴页共用一份**；
  进入某页即清零（曲线只表示"本次进入后连续采样的 8 s"，不把上次来访的旧样本接在时间轴前）。

## 2. 曲线幅度校验（像素级，可复现）

```bash
python3 verify_curve_scale.py raw-accel-curve.png accel
python3 verify_curve_scale.py raw-gyro-curve.png gyro
```

按系列色取出曲线像素，用泳道几何把行号反算成物理量，与合成波形对照：

| 轴 | 实测（从截图反算） | 合成波形期望 | 结论 |
|---|---|---|---|
| 加速度 X | −0.62 .. +0.62 g | ±0.60 g | ✅ |
| 加速度 Y | −0.11 .. +0.11 g | ±0.12 g | ✅ |
| 加速度 Z | +0.69 .. +1.28 g | 0.7 .. 1.3 g | ✅ |
| 陀螺 X | −19.13 .. +19.13 dps | ±20 dps（100 ms 采样最大值 ≈19.4） | ✅ |
| 陀螺 Y/Z | 平线在泳道中线（反算 −0.91 dps） | 0 | ✅（±0.5 px 取整，量程 ±50 dps） |

> 说明：曲线**最新一点**与数值标注取同一帧、同一个 `v[]`。曾用临时插桩日志验证
> `hist[79] == round(v*k)` 与送给数值标签的 `v` 完全一致（日志：`[phywear][dbg] ...
> v=-2224/-444/2884 h79=-2224/-444/2884`）。模拟器截图里偶尔看到的
> "曲线比数字"提前/滞后一个采样（100 ms），是 **adb 在 LVGL 正在写 `/dev/fb0` 时读帧**
> 造成的读撕裂（同一份 `fb0` 的两帧内容分属不同 tick 即可证实），不是渲染逻辑问题。

## 3. 本批发现并修复的两个 bug

1. **自动量程抖动（本批新引入，已修）**：最初用"当前瞬时样本"算峰值 → 正弦过零点时
   量程掉档，陀螺页在两档间反复跳（数值标注写 `+/-50 dps`、曲线却按 `20 dps` 画，
   像素实测曲线幅度达 ±fs）。改为**取整条 80 点窗口的峰值**后，实测曲线幅度回到
   ±19.13 dps，与 ±50 dps 标注自洽。
2. **`pw_ui_root()` 屏幕栈泄漏（既有隐患，顺手修）**：原实现只把 `g_scr_n` 归零、
   不删除仍在栈里的旧屏 → 旧屏的 `pw_scope` 槽位不归还。用 `phywear cap root` 反复
   重建根屏时，第 3 个原始传感器屏起就 `pw_scope: out of slots (6 in use)`，曲线静默消失。
   现改为先删屏再重置栈（正常导航路径本就删屏，行为不变）。

> 上表只能说明"新页与既有曲线页同一量级、主循环无卡死"；**真机帧率不退化需插板后按
> `docs/07 §5` 用同页同 bench 的心跳口径复测**——本批尚未完成，属已知待办。

## 5. 已知限制（如实）

- 模拟器**无地磁驱动**（`/dev/mag0` 打开失败），地磁页数值恒为 `--`、曲线为空；
  该页的**数据通路与曲线仍待在真机上验证**。三页共用同一 builder，加速度/陀螺页已验证。
- 三轴页曲线**只在当前页采样**（省 I2C），切页会清空重来；不保留跨页历史。
- 曲线时间窗 8.0 s、刷新 100 ms，与 `raw_tick_cb` 的节拍绑定。
- 未做（本批范围外）：倾角页指针盘、秒表环形进度、频谱页。
